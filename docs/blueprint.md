# **App Name**: CSCS ProPass

## Core Features:

- Course Content Presentation: Display all course sections including Hero, Authority/Problem, Solution/Features, Curriculum, Instructor, Pricing, Guarantee, and FAQ in a clear, single-page format.
- Interactive Navigation: Implement a sticky navigation bar with internal links, including a mobile hamburger menu that toggles a dropdown for easy access to sections, and smooth scrolling for anchor links.
- Dynamic Accordion Content: Manage the expand/collapse logic for Curriculum modules and FAQ sections, ensuring only one item remains open at a time within each section.
- Conversion-Oriented CTAs: Integrate prominent call-to-action buttons for 'Enroll Now', 'Start Studying Now', and 'Download Free Checklist/Study Guide' with distinct primary and ghost styles.
- Exam Prep AI Assistant: An AI tool that provides instant summaries of specific course topics or generates short practice questions based on content snippets from the course outline, designed to provide a glimpse into the course's value.

## Style Guidelines:

- Primary action color: A vibrant electric blue (#1A91E6), chosen for its association with technology and precision, and serving as the main accent and call-to-action color.
- Hero section background: A deep, authoritative slate-like blue-gray (#18191A), creating a premium, data-driven aesthetic.
- Content section background: A very light, neutral cool gray (#F1F2F4), providing a clean canvas and high readability for body text.
- Secondary accent color: A subtle, light aqua-green (#85E0D9), providing an analogous contrast and complementing the tech-inspired palette without overwhelming the primary actions.
- Headline and body font: 'Inter' (sans-serif) for its modern, clean, and objective aesthetic, ensuring high readability across all text sizes. H1s will be massive and bold.
- Utilize a consistent set of clean, modern, line-style icons for feature cards and key information, reinforcing the 'high-performance sports tech' aesthetic.
- Content presented within a max-width container (approx. 6xl) with abundant whitespace, featuring clean cards with subtle `shadow-lg` and `rounded-2xl` for a premium feel.
- Implement subtle animations for UI elements such as mobile menu toggles, accordion expands/collapses, and a background blur/shadow for the sticky navbar when scrolled.
